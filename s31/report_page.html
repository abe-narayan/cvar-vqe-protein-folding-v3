How to read the numbers

Every comparison in this report is paired, fold-clustered, and judged against its own minimum detectable effect — MDE = 2.8016 × SE, which is per-comparison, never a shared constant. stats_lib.compare is lower-is-better, so a positive delta is a regression. Verdicts:

Result |effect| ≥ 1.0× MDE, fold CI excluding zero, ≥ 4/5 folds agreeing in sign.
Not measured 0.7–1.0× MDE. The instrument cannot tell this apart from nothing — it is not a negative result, and it is not a positive one.
Falsified / worse Below 0.7× MDE, or past MDE on the harmful side.
Oracle · not deployable The arm reads the native structure. It prices a ceiling; it can never ship. Labelled on every occurrence, per the charter.

Three different objects carry three different numbers and are never differenced against each other: the built chain (3.2105 Å, the endpoint), the CA point cloud (3.0483 Å, an intermediate), and the set mean (3.5507 Å). Where a contrast is on the chain, its arms were projected in one process — the λ=0 multi-start argmin amplifies a 1e-7 input spread into branches 1e-1 apart.
